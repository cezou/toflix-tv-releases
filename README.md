# ToFlix TV — téléchargements

APK de l'application Android TV **ToFlix TV**.

## Installer sur la TV avec Downloader (by AFTVnews)

1. Installez **Downloader** sur la TV et autorisez-le à installer des applications inconnues.
2. Dans Downloader, tapez simplement le code : **`2410167`**
   (depuis un navigateur : `aftv.news/2410167`, ou l'adresse `cezou.github.io/toflix-tv-releases`)
3. Installez l'APK, puis ouvrez **ToFlix TV**.

Lien direct de la dernière version :
https://github.com/cezou/toflix-tv-releases/releases/latest/download/ToFlix-TV.apk

Les mises à jour sont proposées automatiquement dans l'application.
